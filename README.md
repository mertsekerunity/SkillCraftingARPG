# Skill Crafting ARPG

A singleplayer 2.5D ARPG prototype built with Unity and C#.

This project focuses on skill crafting, combat feel, enemy behaviour, and a lightweight quest/progression loop. The goal was to prototype a compact ARPG-style gameplay system where the player can combine or select different skill effects and use them in real-time combat.

## Features

- 2.5D ARPG-style movement and combat
- Modular skill system with different damage and effect combinations
- Skill crafting / skill selection gameplay loop
- Enemy AI behaviours such as chasing, attacking, taking damage, and dying
- Hit reactions and basic combat feedback
- Basic quest tracking and progression structure
- Player health / mana UI
- Prototype-level level design and encounter flow

## Tech Stack

- Unity 2022.3.55f1
- C#

## Project Goals

The main goal of this project was to practice building a gameplay-focused ARPG prototype with modular combat systems.

The project explores:

- How to structure reusable skill data and skill behaviours
- How to connect player input, combat logic, UI, and feedback
- How to create simple enemy behaviour and combat encounters
- How to build a small but playable gameplay loop around combat and progression

## Status

Prototype / portfolio project.

This is not intended as a full commercial game. It is a gameplay programming prototype created to demonstrate Unity/C# implementation skills.
